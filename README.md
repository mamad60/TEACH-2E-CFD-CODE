# TEACH-2E-CFD-CODE

Educational and reference implementations of the classic **TEACH-2E** computational fluid dynamics (CFD) code, based on the foundational work of Patankar and Spalding.

This repository provides practical, solved examples and multi-language implementations for learning and teaching finite-volume methods in heat transfer and fluid flow.

## Overview

**TEACH-2E-CFD-CODE** is a collection of educational CFD examples and implementations inspired by the classic TEACH-2E code. It is intended for students, instructors, researchers, and practitioners who want to understand the structure of a finite-volume CFD solver through concrete, readable code.

The repository includes implementations and examples in multiple languages, including:

- **MATLAB**
- **Python**
- **Fortran**

The goal is to make a classic educational CFD resource easier to study, reproduce, and extend.

---

## Why This Repository Matters

### 1. A classic educational reference

TEACH-2E is a well-known teaching-oriented CFD code. It is widely used as a learning reference for:

- finite-volume discretization
- pressure–velocity coupling
- convection–diffusion problems
- iterative solution of flow and heat transfer equations

This repository preserves and presents that educational value through practical examples.

### 2. Multi-language implementations

The availability of examples in **MATLAB, Python, and Fortran** makes the repository useful across different learning and research workflows:

- **MATLAB** for quick experimentation and teaching
- **Python** for modern scientific computing and readability
- **Fortran** for understanding traditional numerical solver structure and performance-oriented code

### 3. Practical solved examples

Rather than only describing theory, the repository provides code examples that help learners connect numerical methods to actual solver implementation.

### 4. Community reference

The repository has been used and referenced by the CFD community. GitHub stars and forks are visible through the badges above and through the repository statistics.

### 5. Maintainer-led modernization roadmap

The repository is maintained by its creator, with a planned focus on documentation, reproducibility, testing, and gradual modernization of the legacy examples.

## Repository Status

This is a **legacy educational repository**, not a production CFD solver.

The code is provided for learning, teaching, and reference. Maintenance efforts are focused on:

- improving documentation and run instructions
- making examples easier to reproduce
- adding validation and regression checks
- modernizing selected parts of the codebase
- preserving the educational value of the original examples
